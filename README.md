# 电气盘柜吊装与转运 AGV 系统

> 基于 ESP32 的电气盘柜室内吊装与转运模拟系统

本项目为课程设计项目，模拟大型厂房电气室内狭窄环境下的电气盘柜吊装、转运与安装过程。

系统以轮式移动平台作为载体，通过吊装机构完成模拟电气盘柜（木质模型）的起吊与放置，并结合双红外循迹、超声波避障、限位检测、BLE 无线通信等功能，实现设备的遥控与自动运输。

项目由 5 人团队协作完成，分别负责嵌入式软硬件、机械结构、上位机及手机 APP 等部分。

# 5. 自动循迹设计

由于实际演示场地采用固定的黑色胶带网格，并且路口统一为十字路口，因此没有让 ESP32 自主判断路口方向，而采用：

> **APP 路线规划 + ESP32 状态机执行**

的控制方案。

APP 可以提前向 ESP32 下发完整路线，例如：

```json
{
    "Route": "LFRLF"
}
```

其中：

| 字符  | 含义 |
| --- | -- |
| `L` | 左转 |
| `R` | 右转 |
| `F` | 直行 |

ESP32 保存路线并维护当前路口索引。

---

## 普通循迹

使用左右两个红外传感器进行夹线循迹。

传感器输出定义：

```text
LOW  → 白色区域
HIGH → 黑色区域
```

对应状态：

| 左传感器 | 右传感器 | 控制   |
| ---- | ---- | ---- |
| 白    | 白    | 正常前进 |
| 黑    | 白    | 向左修正 |
| 白    | 黑    | 向右修正 |
| 黑    | 黑    | 十字路口 |

普通行驶过程中，仅通过单侧黑线检测进行姿态微调。

---

## 十字路口控制

检测到：

```text
左 = 黑
右 = 黑
```

后进入路口动作状态。

以左转为例：

```text
检测十字路口
      ↓
轴心对齐
      ↓
进入盲转阶段
      ↓
持续左转
      ↓
左侧传感器捕获目标黑线
      ↓
退出路口动作
      ↓
恢复普通循迹
```

右转采用镜像控制。

这种设计利用固定赛道与传感器布局的几何关系，将复杂的路口识别问题转化为确定的动作执行问题。

# 6. BLE 通信协议

设备与手机 APP 之间使用 BLE 进行通信。

控制指令采用 JSON 格式。

### 基础运动控制

```json
{
    "cmd": "F"
}
```

支持：

```text
F       前进
B       后退
L       左转
R       右转
S       停止
```

### 吊装控制

```json
{
    "cmd": "UP"
}
```

```json
{
    "cmd": "DOWN"
}
```

### 模式切换

```json
{
    "cmd": "TRACK"
}
```

```json
{
    "cmd": "REMOTE"
}
```

### 速度设置

```json
{
    "cmd": "SET_SPEED",
    "speed": 100
}
```

### 路线下发

```json
{
    "Route": "LFRLF"
}
```

# 7. 状态回传

设备在路线执行过程中向 APP 回传状态。

例如：

```json
{
    "type": "route_progress",
    "state": "executed",
    "cmd": "L",
    "remaining": "FRLF",
    "queue_len": 4
}
```

用于 APP 显示当前：

* 已执行动作
* 剩余路线
* 路口执行进度

# 8. 吊装系统

吊装机构使用 L298N 驱动推杆电机。

ESP32 根据：

* 上升 / 下降指令
* 上限位
* 下限位

控制推杆运动。

基本逻辑：

```text
UP
 ↓
检测上限位
 ↓
未触发 → 上升
触发   → 停止

DOWN
 ↓
检测下限位
 ↓
未触发 → 下降
触发   → 停止
```

限位检测用于防止推杆持续运行造成机械损坏。

## 项目特点

本项目重点解决狭窄室内环境下移动平台的吊装与转运问题，并通过嵌入式控制、无线通信和上位机信息管理实现设备控制与安装过程的信息化。

设备端采用模块化软件架构，将运动控制、传感器采集、通信协议和业务逻辑分离；针对固定网格路线下双传感器难以自主判断路口方向的问题，采用预设路线与状态机结合的控制策略，实现可控、可调试的自动转运过程。
